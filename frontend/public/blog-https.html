HTTP에서 HTTPS로 완전 전환 가이드

2026.04.11 · 6 min read · CyberShield
광고

Google Chrome은 모든 HTTP 사이트를 '안전하지 않음'으로 표시합니다. 30분 안에 전환하세요.

Step 1: 무료 SSL 인증서 발급

# Certbot (Ubuntu/Debian)
sudo apt install certbot python3-certbot-nginx
sudo certbot --nginx -d yourdomain.com -d www.yourdomain.com

Step 2: HTTPS 강제 리다이렉트

# Nginx - Add to server block
server {{
    listen 80;
    server_name yourdomain.com www.yourdomain.com;
    return 301 https://$host$request_uri;
}}

Step 3: 혼합 콘텐츠(Mixed Content) 수정

HTTPS 페이지 내의 HTTP 리소스는 브라우저가 차단합니다. http://를 모두 https://로 교체하세요.

Step 4: Google Search Console 업데이트

  1. HTTPS 버전을 새 속성으로 추가
  2. 업데이트된 sitemap.xml 제출
  3. 크롤링 오류 모니터링
✓ SEO 팁: HTTPS는 구글 검색 직접 랭킹 요소입니다.
