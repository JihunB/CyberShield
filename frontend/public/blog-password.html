기존 비밀번호 규칙이 잘못된 이유

NIST는 2017년 복잡도 규칙을 폐기했습니다. 패스프레이즈가 더 안전합니다.

NIST가 실제로 권장하는 것

  • 패스프레이즈 사용 — '사과-바나나-초록-하늘'이 'P@ssw0rd1'보다 강합니다
  • 길이가 핵심 — 16자 이상이면 8자 복잡 비밀번호보다 강합니다
  • 재사용 금지 — Bitwarden(무료) 같은 비밀번호 관리자를 사용하세요
  • MFA 활성화 — 이메일, 은행, 관리자 계정은 필수
