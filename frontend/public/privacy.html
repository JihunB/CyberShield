개인정보처리방침

개인정보처리방침 · 시행일: 2026년 4월 10일 · CyberShield

CyberShield(이하 "서비스")는 이용자의 개인정보를 중요시하며, 「개인정보 보호법」 등 관련 법령을 준수합니다.

1. 수집하는 정보

  • 이메일 주소 — 보안 리포트 발송 및 에이전트 온보딩 시 이용자가 직접 제공
  • 도메인 주소 — 보안 스캔 수행을 위해 이용자가 직접 입력
  • 업로드된 코드 파일 — 분석 후 즉시 삭제
  • 에이전트 이벤트 데이터 — 보안 이벤트 로그
  • 자동 수집 정보 — IP, 브라우저 종류 (Google Analytics/AdSense)

2. 정보 이용 목적

  • 보안 스캔 결과 이메일 리포트 발송
  • 에이전트 실시간 보안 알림 발송
  • 서비스 품질 개선 및 통계 분석
  • 광고 서비스 제공 (Google AdSense)

3. Google AdSense 및 쿠키

본 서비스는 Google AdSense를 통해 광고를 게재합니다.

  • policies.google.com/technologies/ads
  • 광고 개인화 설정 변경

4. 정보 보유 및 삭제

  • 이메일 주소: 서비스 탈퇴 요청 시까지 보관
  • 스캔 대상 도메인: 90일 보관
  • 에이전트 이벤트: 최대 1년 보관
  • 업로드 코드 파일: 분석 즉시 삭제

5. 제3자 제공

서비스는 이용자의 개인정보를 제3자에게 판매하지 않습니다.

  • Resend (이메일 발송 서비스)
  • Supabase (데이터베이스, 미국 서버)
  • VirusTotal / Google: 도메인 분석

6. 이용자의 권리

이용자는 언제든지 다음 권리를 행사할 수 있습니다:

  • 개인정보 열람, 수정, 삭제 요청
  • 개인정보 처리 정지 요청
  • 에이전트 등록 정보 삭제 요청

요청은 general@jihun.me로 연락해 주세요.

7. 보안

모든 데이터는 HTTPS로 암호화 전송됩니다.

8. 방침 변경

변경 시 7일 전 공지합니다.
